# qa_python

## Тестовое покрытие BooksCollector

Проект содержит набор юнит-тестов для проверки функциональности приложения BooksCollector — системы управления коллекцией книг с возможностью установки жанра и добавления в избранное.

### Список реализованных тестов

**test_initial_state** — проверяет, что только что созданный объект BooksCollector содержит пустой словарь книг и пустой список избранного. Убеждаемся, что начальное состояние класса корректно.

**test_add_new_book_correct_add_book_successful_add** — добавляет книгу с корректным названием и проверяет, что она появляется в словаре books_genre с пустым жанром (по умолчанию жанр не указан).

**test_add_new_book_incorrect_add_book_unsuccessful_add** — параметризованный тест, проверяющий граничные случаи: нельзя добавить книгу с пустой строкой (0 символов) или названием длиннее 40 символов. Валидное название успешно добавляется.

**test_set_book_genre_correct_genre_success** — добавляет книгу и устанавливает ей жанр из допустимого списка. Проверяет, что жанр успешно присвоен книге.

**test_set_book_genre_incorrect_genre_unsuccess** — пытается установить книге жанр, которого нет в списке разрешённых. Проверяет, что жанр не изменился (остался пустым), а метод отработал без ошибок.

**test_get_book_genre** — добавляет книгу, задаёт ей конкретный жанр и проверяет, что метод get_book_genre возвращает именно тот жанр, который был установлен ранее.

**test_get_books_with_specific_genre** — создаёт несколько книг, присваивает им одинаковый жанр «Ужасы» и одну книгу с другим жанром. Убеждаемся, что фильтрация по жанру возвращает только книги с искомым жанром.

**test_get_books_genre** — проверяет, что метод get_books_genre возвращает актуальный словарь со всеми добавленными книгами и их жанрами.

**test_get_books_for_children** — добавляет две книги: одну с жанром без возрастного рейтинга («Фантастика»), другую — с возрастным рейтингом («Ужасы»). Проверяет, что в список для детей попадает только книга, не имеющая возрастных ограничений.

**test_add_book_in_favorites** — добавляет книгу в словарь, затем в избранное. Проверяет, что она появляется в списке избранных книг.

**test_delete_book_from_favorites** — добавляет книгу в избранное, затем удаляет её оттуда. Убеждаемся, что список избранного становится пустым.

**test_get_list_of_favorites_books** — добавляет две книги в избранное и проверяет, что метод возвращает корректный список, содержащий обе добавленные книги.
